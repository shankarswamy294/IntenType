How it works

Three seconds, start to finish

No switching apps, no clicking, no copy-pasting. Just speak.

Hold Right Option

Press and hold the ⌥ Right Option key. A waveform pill appears at the top of your screen and recording begins instantly.

Say what you mean

Talk like you normally would. Fillers, fragments, rambling — it doesn't matter. Whisper transcribes it locally.

Release — it types

GPT polishes the transcript, removes filler words, fixes grammar, and injects the result into whatever text field is active.

Features

Everything in one hotkey

No cloud microphone. No subscription. No browser extension.

Audio stays on your Mac

Whisper runs entirely locally. Your voice never touches a server. Transcription works offline.

GPT cleans the transcript

Filler words gone, grammar fixed, intent preserved. The output reads like you drafted it, not like you rambled it.

Gets sharper over time

Every rewrite is stored locally. Future GPT calls use your own history as examples so the style matches yours exactly.

Works in any app

Injects via clipboard + keystroke. Slack, Mail, VS Code, Notion, Terminal, browsers — anywhere a cursor is active.

Skips sensitive fields

Detects password fields and secure input mode. Injection is automatically blocked so nothing leaks.

Bring your own key

No IntenType account. No IntenType subscription. You pay OpenAI directly — typically cents per day of heavy use.

Setup

Running in under 3 minutes

One drag-and-drop, three permission prompts, one API key.

1

Download & install

Download IntenType.dmg, open it, drag IntenType into Applications. Launch it — the IntenType icon appears in your menubar at the top right.

2

Grant three permissions

Open System Settings → Privacy & Security and enable IntenType for each:

Accessibility Injects text into the focused field
Input Monitoring Detects when Right Option is held
Microphone Records while the key is held
3

Paste your OpenAI key

Click the IntenType icon in your menubar → Set API Key… and paste a key from platform.openai.com/api-keys. The key is stored locally — never uploaded anywhere.

4

Hold Right Option and speak

Click into any text field anywhere on your Mac. Hold ⌥ Right Option, speak, release. The polished text appears immediately.
