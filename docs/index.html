Setup

Up in 3 minutes

One download, three permission grants, one API key.

1

Download & install

Download IntenType.dmg, open it, and drag IntenType to your Applications folder.

2

Grant three permissions

macOS will ask for these on first launch. Go to System Settings → Privacy & Security and enable:

♿
AccessibilityLets IntenType detect the focused field and inject text
⌨️
Input MonitoringLets IntenType detect when you hold the Right Option key
🎙️
MicrophoneRecords your voice while the key is held
3

Add your OpenAI key

Click the 🎤 menubar icon → Set API Key…
Get a key at platform.openai.com/api-keys (free to start).

4

Start talking

Click in any text field anywhere on your Mac, hold Right Option, speak, release. Done.
