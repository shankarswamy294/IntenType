How it works

Three seconds, start to finish

No switching apps. No clicking. No copy-pasting. Just speak.

Step 01

Hold ⌥ Right Option

Press and hold the Right Option key on your keyboard. The animated waveform overlay appears at the top of your screen — recording begins instantly.

Step 02

Speak naturally

Talk like you normally would. Filler words, run-on sentences, rambling — it doesn't matter. Whisper captures and transcribes it all locally on your device.

Step 03

Release — it types

GPT rewrites the transcript — removes filler words, fixes grammar, preserves your intent — and injects the polished result directly into the active text field.

Features

Everything in one hotkey

No cloud microphone. No subscription. No browser extension.

Audio stays on your Mac

Whisper runs entirely on-device. Your voice is never sent to a server. Transcription works fully offline.

GPT cleans the transcript

Filler words gone, grammar fixed, intent preserved. The output reads like you drafted it, not like you rambled it.

Works in every app

Injects via CGEvent keyboard simulation. Slack, Mail, VS Code, Notion, Terminal, browsers — anywhere a cursor is active.

Skips sensitive fields

Detects password fields and secure input mode automatically. Injection is blocked so nothing leaks where it shouldn't.

Gets sharper over time

Every rewrite is stored locally. Future calls use your own history as examples so the style matches yours exactly.

Bring your own key

No IntenType account or subscription. You pay OpenAI directly — typically pennies per day of heavy use.

Setup

Running in under 3 minutes

One drag-and-drop, three permission prompts, one API key.

1

Download & install

The easiest way — open Terminal and paste one line:

curl -fsSL https://raw.githubusercontent.com/shankarswamy294/IntenType/main/scripts/install.sh | bash

Downloads, installs to Applications, and removes Gatekeeper — no security warnings.

Prefer the DMG? You'll see a Gatekeeper warning:

Click Done → System Settings → Privacy & Security → scroll down → Open Anyway → enter password. One-time only.

2

Grant three permissions

The setup wizard walks you through each one automatically. Or open System Settings → Privacy & Security manually:

Input Monitoring Detects Right Option key
Microphone Records while key is held
Accessibility Skips password fields
3

Add your OpenAI key

Click the IntenType icon in your menubar → Set API Key… and paste a key from platform.openai.com/api-keys. Stored locally — never uploaded anywhere.

4

Hold Right Option and speak

Click into any text field. Hold ⌥ Right Option, speak, release. Polished text appears instantly.
